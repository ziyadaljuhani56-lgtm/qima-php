# منصة قيمة (نسخة PHP / HTML / JS / CSS / SQL)
مشروع متكامل وجاهز للتشغيل المباشر على **XAMPP** أو أي استضافة PHP/MySQL (cPanel / Apache / Nginx).

---

## 🚀 طريقة التشغيل على XAMPP في 3 خطوات بسيطة:

### 1. نقل المجلد إلى XAMPP
- انسخ مجلد `qima-php` إلى داخل مسار `htdocs` في XAMPP:
  `C:\xampp\htdocs\qima-php`

### 2. استيراد قاعدة البيانات (MySQL)
1. شغّل برنامج **XAMPP Control Panel** وتأكد من تشغيل خدمتي **Apache** و **MySQL**.
2. افتح المتصفح وادخل إلى لوحة التحكم: `http://localhost/phpmyadmin/`
3. اضغط على **New (جديد)** وأنشئ قاعدة بيانات باسم: `qima_db` بترميز `utf8mb4_unicode_ci`.
4. اضغط على تبويب **Import (استيراد)**، واختر الملف:
   `qima-php/database.sql` ثم اضغط **Go (تنفيذ)**.

### 3. فتح الموقع في المتصفح
- ادخل إلى الرابط:
  `http://localhost/qima-php/`

## 📁 هيكلية ملفات المشروع:
- `config.php`: ملف إعدادات الاتصال بقاعدة البيانات عبر PDO وتخزين الجلسات.
- `database.sql`: مخطط قاعدة البيانات مع جداول المستخدمين، الموارد، الخدمات، والمنتجات.
- `index.php`: الصفحة الرئيسية وتضم نبذة وسوق العروض والخدمات.
- `market.php`: سوق الموارد المستدامة مع إمكانية التصفية والتصنيف والبحث.
- `product.php`: صفحة تفاصيل المنتج والمورد الفردي.
- `services.php`: صفحة خدمات المنصة (اللوجستيات، تقارير ESG، والتحليلات).
- `insights.php`: صفحة المؤشرات والأثر البيئي.
- `about.php`: صفحة عن منصة قيمة.
- `contact.php`: صفحة التواصل وإرسال الاستفسارات وتوريد الموارد وحفظها في قاعدة البيانات.
- `terms.php`: صفحة الشروط والأحكام الكاملة.
- `privacy.php`: صفحة سياسة الخصوصية واستخدام البيانات.
- `login.php`: تسجيل الدخول مع نافذة منبثقة تفاعلية لـ "نسيت كلمة المرور".
- `signup.php`: إنشاء حساب مستخدم جديد وتشفير كلمة المرور.
- `profile.php`: إدارة الملف الشخصي ومتابعة الاستفسارات السابقة.
- `dashboard.php`: لوحة تحكم الإدارة لمتابعة الاستفسارات وإضافة منتجات للسوق.
- `assets/css/style.css`: التصميم الأنيق والهوية البصرية لمنصة قيمة.
- `assets/js/main.js`: تفاعلات JavaScript، القائمة، والنوافذ المنبثقة.
